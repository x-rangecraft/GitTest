# Git测试

## 基础部分

1. 目标仓库地址 https://github.com/x-rangecraft/GitTest
2. 拉到本地
3. 创建一个自己的分支 feature/[name]
4. 创建一个自己的名字文件 提交到远端自己对应分支
5. 拉取其他人的提交内容
6. 合并后的内容提交到自己分支

## 进阶部分

1. 在test.py里面增加自己的名字
2. 提交到远端自己的分支
3. 合并其他人的提交(需要处理冲突)
4. push到远端自己的分支

## 加强部分

1. 目标分支 feature/target
2. 只拉取目标分支属于自己名称的提交合并到自己的分支
